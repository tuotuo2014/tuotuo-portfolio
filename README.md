# TUOTUO 作品集

展示五个项目的个人网站，包含中英文切换、图片图集、硬件三维预览和鼠标交互。

双击 `index.html` 或使用静态 HTTP 服务打开。Three.js 模型首次加载需要联网。

## 项目仓库

- [chat-box](https://github.com/tuotuo2014/chat-box)
- [dustline](https://github.com/tuotuo2014/dustline)
- [personality-test](https://github.com/tuotuo2014/personality-test)
- [demon-slayer-pixel-game](https://github.com/tuotuo2014/demon-slayer-pixel-game)
- [novel-website](https://github.com/tuotuo2014/novel-website)

部分项目仓库暂为图片或项目档案，具体收录状态见各仓库说明。
